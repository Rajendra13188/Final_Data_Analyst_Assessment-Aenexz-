# California House Price Prediction

## Overview
This project predicts California house prices using Machine Learning models. The dataset was cleaned, preprocessed, and multiple regression models were trained and compared.

## Dataset
- California Housing Dataset

## Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Model Performance

| Model | R² Score |
|--------|----------|
| Linear Regression | 0.6137 |
| Decision Tree | 0.6418 |
| Random Forest | 0.8075 |

**Best Model:** Random Forest Regressor
